NEON HARBOR is a complete open-world crime game that plays offline in a desktop browser, in the spirit of GTA 6. Explore the sunset port city of Puerto Solano on foot and by car: steal and drive any car, outrun a five-star wanted system with police interceptors that chase and ram you, fight with a hitscan pistol, and work through a four-mission story chain (First Wheels, Special Delivery, Harbor Run, Hot Package) plus endless courier runs. It has lane-following traffic AI, pedestrians who flee danger, a full HUD with a live minimap, BUSTED and WASTED states, synthesized WebAudio sound, and a localStorage save with Continue. Built with Three.js, vendored locally — the game makes zero network requests at runtime.

Controls: WASD to move, mouse to look, Shift to sprint, E to enter/exit a car, F or left click to shoot, R to reload, Esc/P to pause, M to mute.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
